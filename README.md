# Apuração 2026 — SP

Página para a equipe acompanhar a apuração do 1º turno (4/10/2026) dos nossos candidatos a Deputado Federal e Estadual em SP.

**Link:** https://luishenriquedorti-collab.github.io/apuracao-2026/

- Dados oficiais do TSE (resultados.tse.jus.br), lidos direto pelo navegador e atualizados a cada 60 segundos.
- Mostra votos em SP, % de válidos, posição no estado, votos na cidade escolhida (padrão: Nova Granada) e a situação oficial (Eleito / Suplente / Não eleito).
- Para ver como fica com votos (dados fictícios): adicione `#demo` ao fim do link.
- Para mudar candidatos, edite a lista `CARGOS` no início do `<script>` em `index.html`.
