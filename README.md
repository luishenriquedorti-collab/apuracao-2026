# Apuração 2026 — SP

Página para a equipe acompanhar a apuração do 1º turno (4/10/2026) em SP, com duas abas:

- **Nossos deputados:** os candidatos a Deputado Federal e Estadual que acompanhamos.
- **Presidente, Governo e Senado:** todos os candidatos desses cargos, com os votos na cidade escolhida.

**Link:** https://luishenriquedorti-collab.github.io/apuracao-2026/

- Dados oficiais do TSE (resultados.tse.jus.br), lidos direto pelo navegador e atualizados a cada 60 segundos.
- Na aba de deputados: votos em SP, % de válidos, posição no estado, votos na cidade escolhida (padrão: Nova Granada) e a situação oficial (Eleito / Suplente / Não eleito).
- Para ver como fica com votos (dados fictícios): adicione `#demo` ao fim do link.
- Para mudar candidatos, edite a lista `CARGOS` no início do `<script>` em `index.html`.
